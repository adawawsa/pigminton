# 🐷 ピグミントン (Pigminton)

ブタミントンのデジタル版プロトタイプ - Web技術で実装したブラウザゲーム

## 概要

「ピグミントン」は、メガハウスの卓上アクションゲーム「ブタミントン」をHTML5/Canvas/WebGLで再現したブラウザゲームです。空気力学シミュレーションと直感的なタッチ操作により、オリジナルの「ソフビ人形を握って空気を送り出す」独特の感覚を再現しています。

## 主な機能

### ✨ 実装済み機能

- **物理演算エンジン**
  - 空気抵抗シミュレーション（drag coefficient）
  - 重力と浮力のバランス
  - 風の力のベクトル計算と距離減衰

- **操作システム**
  - タッチ/クリック操作（スワイプ&ホールド）
  - キーボード操作（A/Lキー）
  - マイク入力対応（実験的機能）

- **ゲームモード**
  - 1vs1対戦モード
  - スコア管理（11点先取）
  - リアルタイム物理演算

- **ビジュアル**
  - ソフビ感のあるブタのデザイン
  - 風のエフェクト可視化
  - 羽根の回転と浮遊アニメーション
  - レスポンシブデザイン

- **サウンド**
  - Web Audio APIによる動的な「ブー」音生成
  - 風の強さに応じた音程変化

## セットアップ

### 必要要件

- モダンブラウザ（Chrome, Firefox, Safari, Edge）
- ローカルWebサーバー（オプション）

### 起動方法

#### 方法1: 直接HTMLを開く

```bash
# ブラウザで index.html を開く
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows
```

#### 方法2: ローカルWebサーバー

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合
npx http-server -p 8000

# ブラウザで http://localhost:8000 を開く
```

## 遊び方

### 基本操作

1. **ゲーム開始** - 「ゲーム開始」ボタンをクリック
2. **風を送る**
   - プレイヤー1: 左側のブタをタップ（またはAキー）
   - プレイヤー2: 右側のブタをタップ（またはLキー）
3. **長押しでチャージ** - 長く押すほど強い風が出ます
4. **羽根を返す** - 相手のコートに羽根を落とすと得点

### ルール

- 羽根が自分のコート（地面）に落ちると相手に1点
- 先に11点獲得したプレイヤーが勝利
- ネットを越えて羽根を打ち返そう！

### マイク入力モード（実験的）

1. 「🎤 マイク入力」ボタンをクリック
2. ブラウザのマイクアクセスを許可
3. ブタに向かって息を吹きかける
4. 音声の強さに応じて風が発生

## 技術仕様

### アーキテクチャ

```
pigminton/
├── index.html      # メインHTMLファイル
├── style.css       # スタイルシート
├── physics.js      # 物理演算エンジン
├── game.js         # ゲームロジック
└── README.md       # このファイル
```

### 物理演算パラメータ

レポート仕様に基づいた主要パラメータ：

| パラメータ | 値 | 説明 |
|----------|-----|------|
| 羽根の質量 | 0.005 kg | 5グラム |
| 空気抵抗係数 | 1.2 | 高い抵抗値 |
| 風の最大強度 | 50 N | 最大推進力 |
| 風の到達距離 | 200 px | 効果範囲 |
| チャージ速度 | 80/秒 | 充填レート |

### クラス構造

#### `Vector2D`
2Dベクトル演算用のユーティリティクラス

#### `Shuttlecock`
羽根（シャトルコック）の物理挙動を管理
- 位置、速度、加速度
- 空気抵抗の計算
- 浮遊状態の検知

#### `WindForce`
ブタからの風の力を表現
- チャージシステム
- 距離減衰計算
- プレイヤー別の方向制御

#### `PhysicsWorld`
物理シミュレーション全体を統括
- 境界判定
- 衝突検出
- ゲームフィールド管理

#### `PigmintonGame`
ゲーム全体のコントローラー
- ゲームループ
- 入力処理
- レンダリング
- スコア管理

## カスタマイズ

### 物理パラメータの調整

`physics.js`内のパラメータを変更することで、ゲーム性を調整できます：

```javascript
// 羽根の挙動を変更
this.dragCoefficient = 1.2;  // 空気抵抗（大きいほどゆっくり落ちる）
this.mass = 0.005;           // 質量（重いほど早く落ちる）

// 風の強さを変更
this.maxStrength = 50;       // 最大風力
this.chargeRate = 80;        // チャージ速度
```

### ビジュアルの変更

`style.css`でカラースキームやアニメーションをカスタマイズ：

```css
/* ブタボタンの色 */
.pig-button {
    background: linear-gradient(135deg, #ffeaa7 0%, #fab1a0 100%);
}

/* 背景グラデーション */
body {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

## トラブルシューティング

### マイク入力が動作しない
- HTTPSまたはlocalhostでアクセスしているか確認
- ブラウザのマイク権限を確認
- コンソールにエラーが出ていないか確認

### 物理挙動がおかしい
- ブラウザのハードウェアアクセラレーションを有効化
- デバッグモードを有効化（`game.js`内の`if (false)`を`if (true)`に変更）

### パフォーマンスが悪い
- ブラウザのタブを減らす
- キャンバスサイズを小さくする
- パーティクルエフェクトを削減
